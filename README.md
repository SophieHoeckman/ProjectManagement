# DecisionMaking

Group project for the Project Management course using Python and ProPy.

## Research direction

**Research question:** Under what levels of resource scarcity does selecting the fastest execution mode stop being the best strategy for minimizing total project duration?

**Hypothesis:** Fastest modes perform best when resources are abundant, while balanced or adaptive duration-resource strategies perform better when resources are scarce.

## Local setup

1. Download ProPy from the official `Data-driven-project-management-with-Python` release.
2. Extract it locally as `DDPM_ProPy_V1/` in this repository.
3. Download the selected MMLIB instances separately.
4. Install the Python dependencies used by ProPy.

Downloaded ProPy/MMLIB files and generated results are intentionally excluded from Git. Only our own analysis code, notebooks, documentation, and selected final figures should be committed.
